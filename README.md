Virtual Hand Keyboard
☆Overview
This is a virtual keyboard built using Python. It allows users to type using an on-screen keyboard interface.

☆Features
Alphabet input (A–Z)
Punctuation (comma, period)
Backspace functionality
Simple interactive UI

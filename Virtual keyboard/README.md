# Virtual hand tracking on-screen keyboard

A computer-vision based project that uses hand tracking that is supported by cv2 and mediapipe. 
application requires webcam. Users pinch their middle and index togather over the letter which they want to type. release fingers to stop typing.

## Features
- Real-time hand tracking
- Pinch-to-type interaction
- On-screen keyboard
- Backspace support
- Cooldown system to prevent double typing

## Tech Stack
- Python  
- OpenCV
- MediaPipe
